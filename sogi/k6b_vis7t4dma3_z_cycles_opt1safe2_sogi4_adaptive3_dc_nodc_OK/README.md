# SOGI-PLL Project Apex (k6b)

## Overview
The most advanced version in the repository. It combines all previous innovations into a single, high-performance grid synchronization system with predictive modeling and high-precision math.

## Key Features
- Adaptive single-gain predictive model (`phase_change ≈ gain_est * control`).
- Kahan summation for near-perfect integration accuracy.
- Advanced phase unwrapping for continuous tracking.
- Tustin-transformed SOGI filter.
- Window-based DC offset smoothing.
- Comprehensive timing accounting and CPU headroom monitoring.
