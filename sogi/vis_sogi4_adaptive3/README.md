# Adaptive SOGI Visualizer (Base)

## Overview
The baseline version of the Era 5 high-performance visualization series. It introduces the Tustin-transformed SOGI filter and TileManager rendering.

## Key Features
- Tustin SOGI implementation.
- TileManager system for optimized 'dirty-rect' OLED rendering.
- Frequency-adaptive sampling logic.
- Real-time waveform plotting.
