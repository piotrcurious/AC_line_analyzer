# SOGI Extended Kalman Filter (EKF)

## Overview
This version replaces the standard PI-based Loop Filter with an Extended Kalman Filter (EKF) for state estimation. It provides superior tracking performance in the presence of high noise and grid distortion.

## Key Features
- EKF-based frequency and phase estimation.
- Non-linear state transition modeling.
- Optimal gain calculation for noise rejection.
- Tuned for grid-synchronization scenarios.
